## 🚀 The Build: Dispatcher Intelligence Tool

While customer anxiety is the loudest symptom in the QuickMove process, the actual root cause of delays happens in the middle of the funnel: **Property Partner Outreach (WF04)**. 

Currently, ops agents manually match customer profiles with local property partners and manually type out WhatsApp requests. To solve this, I built the **Dispatcher Intelligence Tool**.

### Features:
1.  **Algorithmic Matching:** Instantly filters a database of property partners based on strict customer parameters (Destination City, Structural Configuration, and Pet-Friendly requirements).
2.  **Performance Ranking:** Sorts eligible partners by their historical performance score and average response time, ensuring QuickMove only works with the best vendors.
3.  **Automated Prompt Generation:** Dynamically generates perfect WhatsApp outreach templates customized for each partner, including SLA expectations and property upload links.
4.  **1-Click Copy:** Allows the Ops Agent to copy the generated template instantly to their clipboard, reducing a 10-minute manual task to 15 seconds.
5.  **Premium UI:** Designed with a striking, high-end "Glassmorphic" dark-mode aesthetic to provide a highly polished user experience for the internal ops team.
